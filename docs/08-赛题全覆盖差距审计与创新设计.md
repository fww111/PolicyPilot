## 三、创新设计（每个附效果保障）

### 创新 C：Skills 三层编排体系（补 G1，最高优先）

**设计**：把五步工作流映射到 Nexent Skill 的分层结构——
- **L1 原子层**：5 个 MCP 工具（已有）
- **L2 技能层**：3 个 Skill（Nexent UI 构建，可视化 DAG）
  - `画像技能`：extract_enterprise_profile + GB 归一校验
  - `匹配技能`：query_policy_graph(match) → PPR 候选 + check_policy_validity 过滤
  - `审查技能`：check_eligibility 批量 + 互验仲裁
- **L3 编排层**：主智能体按角色提示词调度三个 Skill

**效果保障**：Nexent Skill 是平台原生功能（UI 可视化构建），构建即验证；每层有独立截图与调用记录；评分细则的"分层编排逻辑清晰、模块解耦"直接对着 L1/L2/L3 讲。

### 创新 B：政策附表多模态理解管道（补 G2）

**设计**：政策文件第二形态——附表（补贴标准表）是条款的规整化表达：
- pdfplumber 表格抽取（已就绪）+ MinerU 复杂版面（实装 API）
- 表格 → 结构化"事项-条件-金额"矩阵 → **直接生成 Subsidy + Condition 节点**（表格数据天然规整，抽取准确率高于正文，效果有保障）
- 资产血缘：表格行 → 条款 → 源文档

**效果保障**：抽 10 份含附表的政策，人工比对表格还原准确率（表格是结构化的，预期 >90%）；正文 vs 表格的抽取质量对比数据直接进论文（多模态价值实证）。

### 创新 A：政策数据资产目录（补 G3，差异化亮点）

**设计**："沉睡资产激活"叙事的具象化——
- 资产登记表：asset_id / 来源 / 格式 / 抓取时间 / 解析状态 / 血缘（文档→表格→三元组）
- 资产状态机：`沉睡(raw) → 解析(parsed) → 结构化(structured) → 服务中(serving)`
- 溯源链升级：evidence + **asset_id**（任何推荐结论可回溯到原始文件的原始表格行）

**效果保障**：纯元数据工程零风险；目录统计（390 源/140 全文/585 边的资产转化漏斗）直接可视化进演示视频；"唤醒率"指标（沉睡→服务中占比）是评委没见过的新指标。

### 创新 D：本体增量演化-新增侧（补 G4）

**设计**：B3 的 100 份江苏文件天然是分批数据——
- 分 5 批入库，每批后跑 schema diff（发现未登记的实体类型/关系类型/字段）
- 输出"本体版本曲线"：v1.0 → v1.x，每批新增 schema 元素数收敛曲线（证明本体趋于稳定）

**效果保障**：纯统计分析，B3 数据已有；收敛曲线是论文 C1 的一部分。

### 创新 E：城市迁移实证（补 G5，附加分 10 分）

**设计**：pipeline 迁移到常州/无锡（同为静态 CMS 站点）——
- 记录：改了几行配置、爬取耗时、抽取通过率、图谱规模
- 对照：苏州（首发城市）vs 常州（迁移城市）的各环节成本

**效果保障**：爬虫框架已验证可移植；迁移实验只换数据源配置，代码零改动 = "模板"的最强证明。
