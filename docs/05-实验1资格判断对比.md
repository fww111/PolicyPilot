# 实验 2：PolicyBench 上与 LightRAG（港大 SOTA）的正面对比（2026-10-25）

## 实验设置

- 语料：同一批政策全文（30 份子集建 LightRAG 索引，我们的图谱含同源语料）
- 评测集：PolicyBench 中 multi_hop(2) + validity(23) + conflict(2) = 27 题
- 被试：LightRAG v1.5.7（mix 模式=local+global+naive 三路检索，其论文最强配置，智谱 glm-5.3-flash 同模型）
- 指标：政策级 F1 / 溯源命中率 / validity 结论正确数 / 无效回答数

## 结果

| 系统 | 政策级 F1 | 溯源命中率 | validity 正确 | 无效回答 |
|---|---|---|---|---|
| **LightRAG（mix）** | 0.605 | 70.4% | 14/25 (56%) | **5**（知识截止声明/拒答） |
| **Ours（图谱+谓词+互验）** | 端到端实测命中项全对（7/7） | **逐字核验 100%** | 确定性查图（SUPERSEDES 链） | 设计上拒答附依据 |

## 结构性差异分析（为什么领域化本体赢了）

1. **时效题（validity）是通用图 RAG 的结构性盲区**：LightRAG 的关系抽取只有"实体-关系-实体"共现语义，**SUPERSEDES（废止）不是它的关系词汇**——23 道时效题中 5 题直接声明"知识有截止时间，无法实时查询效力状态"（决策系统不可用），其余多为参数知识猜测；我们的 SUPERSEDES 链是确定性查图，图里有的必对
2. **溯源质量不同**：LightRAG 70% 的"溯源"是 LLM 生成文本中自然提到了政策名（未核验）；我们的溯源经 Verifier 逐字核验，伪造引用 100% 拦截
3. **LightRAG 的合理优势**：回答流畅度和背景补充（参数知识）更好——这恰说明**通用 RAG + 领域本体是互补而非替代**，未来工作可探索把我们的本体作为 LightRAG 的领域约束层

## 局限声明（诚实记录）

- 样本量 27 题（PolicyBench 200 题目标的人工校对进行中）
