# N01：业务任务规范（T1–T3）与试标案例模板

> 状态：**规范定稿（v1）**；试标案例待建（目标 30–50 个，计划 13.2 节）。
> 计划依据：第 3.2 节任务表、第 3.3 节贯穿样例、第 7.1 节能力问题。
> 主场景：制造业质量异常与标准变更影响追溯（计划 3.1 节）。

## 1. 通用约定

### 1.1 结论四态

所有任务的结论状态只能取以下四值（对应契约 `ConclusionStatus`）：

| 状态 | 含义 | 判定条件 |
|---|---|---|
| `supported` | 当前证据支持结论 | 关键前提全部成立且证据可定位 |
| `refuted` | 当前证据反对结论 | 存在明确反对证据且无冲突 |
| `unknown` | 证据不足 | 关键输入缺失/不可访问/标准适用性未确认 |
| `conflict` | 有效证据冲突 | 同时存在支持与反对的有效证据 |

**检索未找到 ≠ 命题为假**；只有契约中明确采用闭世界假设的规则才允许将缺失判为否。

### 1.2 错误等级（验收时对系统输出分类）

| 等级 | 定义 | 示例 |
|---|---|---|
| E1 关键错误 | 错误结论被当作正常输出（假阳性放行）；证据越权泄漏 | 数值超差却判合格；无权限证据出现在证据包 |
| E2 严重错误 | 结论错误但可被下游复核发现；或应重审结论未标记 | 标准已更新却未进入重审清单 |
| E3 一般错误 | 定位/单位/别名等辅助信息错误，结论本身正确 | 锚点指向错误页码 |
| E4 保守降级 | 正确地输出 unknown/conflict 并给出缺失项 | 证书缺失时输出"检验有效性待复核" |

**E4 不计为错误**，是正确行为；E1 是发布阻断项（计划 13.5 节）。

## 2. 任务规范

### T1：跨文档质量证据审核

| 项 | 规范 |
|---|---|
| 输入资产 | 产品图纸（图像/PDF）、检验表（XLSX）、校准记录（PDF）、适用规范（版本化 PDF） |
| 推理路径 | 产品特征 → 检验项 → 测量值/单位 → 仪器与校准 → 适用标准条款 |
| 输出对象 | `DecisionRecord`（四态）+ 证据依赖图（锚点到原文位置） |
| 正常输出 | 合格 / 不合格（附每条前提的锚点、规则、标准版本） |
| 必须降级的情形 | ① 测量时间在校准有效期外 → unknown（检验有效性待复核）；② 单位不一致且无法程序换算 → unknown；③ 证据无权限 → unknown（不泄漏存在性） |
| 关键验收 | E1=0；`missing_items` 必须列出全部缺失项；撤证后重跑不沿用旧结论 |

### T2：标准变更影响分析

| 项 | 规范 |
|---|---|
| 输入资产 | 旧标准版本、新标准版本、历史决策记录、历史事实 |
| 推理路径 | 条款差异（`ChangeSet`）→ 受影响概念/规则/事实 → 历史决策 → 复核任务 |
| 输出对象 | `ChangeSet` + 三类清单：必须重审 / 无需重审 / 适用范围待确认 |
| 正常输出 | 影响清单（带依赖边语义：`supersedes`/`uses_rule`/`aligned_to` 等） |
| 必须处理的情形 | ① 新条款首次适用、适用范围扩大、新增例外 → 走适用谓词扫描路径（计划 8.2 节第 3 步）；② 仅排版变化 → 不触发重审 |
| 关键验收 | 影响召回目标 ≥98%（计划 13.5）；未受影响决策保持率达标；回归失败保留旧版本 |

### T3：异常关联与复检计划

| 项 | 规范 |
|---|---|
| 输入资产 | 异常报告、批次谱系、工艺记录、供应商证明 |
| 推理路径 | 异常现象 → 相关批次/工艺 → 支持与反对证据 → 候选原因 → 最小补证项 |
| 输出对象 | 排序的**原因假设**（非因果结论）+ 反证 + 复检建议草稿 |
| 语义约束 | 只有受控实验/领域机制/识别设计支持时才可升级为因果结论；路径可达 ≠ 原因成立 |
| 关键验收 | 每个假设附支持/反对证据与置信排序依据；复检建议是最小补证集 |

## 3. 能力问题（Competency Questions，种子集）

本体构建必须先通过以下问题定义（计划 7.1 节，目标 20–30 个，当前 10 个种子）：

1. 某项测量应使用哪个标准版本及哪条规则？
2. 哪些批次共用同一检验设备，且该设备在检验时不满足校准条件？
3. 标准条款 X 被替换后，哪些结论需要重审？
4. 哪些记录只有规格要求但没有实测证据？
5. 某型号术语被合并/拆分后，是否会错误扩大规则适用范围？
6. 某资产在系统中有哪些外部系统标识，各自的映射依据是什么？
7. 某决策当时依据的版本集合是什么？按当前知识重算结论是否变化？
8. 哪些证据锚点因权限变化对当前用户不可见？
9. 某检验项的测量值、单位与标准化值分别是什么，锚点在哪？
10. 哪些候选事实处于同一命题的冲突状态？

## 4. 试标案例模板（30–50 个目标）

每个案例一条记录，存于 `docs/g0-baseline/cases/T{1|2|3}-{NN}.md`：

```yaml
case_id: T1-001
task: T1
difficulty: easy|medium|hard          # 按跳数/冲突/时序复杂度预分
assets: [drawing-A.pdf, inspection-B.xlsx, calibration-C.pdf, standard-D-v1.pdf]
ground_truth:
  conclusion_status: supported|refuted|unknown|conflict
  allowed_conclusions: [...]           # 争议案例允许的结论集合
  required_evidence: [anchor 描述列表]  # 必要证据，缺失则判 unknown 错误
  applicable_standard: "D@v1#5.2"
error_conditions: [E1 陷阱描述]        # 本案例设计的易错点
notes: 双人标注/仲裁状态
```

**划分规则（计划 13.2）**：按案件/批次/设备族/文档来源或时间划分开发/验证/锁定集，禁止随机碎片切分；同模板合成变体不得跨集合。
